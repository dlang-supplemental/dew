= Windowed Vello demo

GLFW window that attaches dew's `VelloRenderBackend` and presents a tiny UI (text, button, checkbox, mesh embed).

== Requirements

* Rust toolchain: `cargo` / `rustc` (vello-d builds the Rust bridge in `preBuildCommands`)
* DUB config: this example selects dew's `gpu` configuration (sibling `../vello-d` until registry `~>0.1.4`)
* **Windows:** MSVC `link.exe` + Windows SDK libs on `PATH`
* **Linux:** usual C toolchain; GLFW with X11 and/or Wayland native access

macOS needs a Metal surface constructor in vello-d (not yet).

== Build / run

From the dew repo root:

[source,sh]
----
dub build --root examples/vello-window
dub run --root examples/vello-window
----

If the vello-d bridge link step fails on Windows, open an MSVC developer shell (full VC + Windows SDK) and retry.

== Headless

CI and software paint stay on `examples/gallery` with `DewHeadless` / `dub test -c headless`. Do not set `DewHeadless` on this example.
