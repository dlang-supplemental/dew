= Roadmap

Known gaps and near-term priorities for **dew** (engine). App-kit gaps live primarily in link:https://github.com/dlang-supplemental/dui[`dui`]; that repo points here for engine work.

Slogan: *Dew it!*

== Priority next

. [*x*] Real **windowed Vello demo** (`examples/vello-window` — GLFW + `VelloRenderBackend`)
. [*x*] **Touch** capture, multi-touch move, and drag-vs-tap (`PointerRouter`)
. [*x*] **Remove** the legacy `rmgui` DUB package (done — use `dew` only)
. [*x*] Flesh out **dui** state / rebuild / forms / focus / nav / gestures (see dui roadmap)
. [*x*] Vello glyphs / paths / clips on GPU backend (needs `vello-d` ≥ 0.1.4)
. [*x*] Mesh embed scaffolding (`MeshView` + `ImageBlit`; soft triangle until shared device)
. [*x*] Non-Windows window host (Linux X11 / Wayland via vello-d; macOS still open)

== Engine gaps

=== Window host

* [*x*] Packaged GLFW demo attaching `VelloRenderBackend` (`examples/vello-window`)
* [*x*] Linux X11 / Wayland attach paths in demo (when GLFW + vello-d succeed)
* [ ] macOS Metal / Cocoa surface constructor (blocked on vello-d)
* Gallery remains headless for CI (`DewHeadless`)

=== Vello / 2D GPU

* [*x*] Software backend honors `ClipPush` / `ClipPop`
* [*x*] Vello backend: real clip layers, stroke rects, rounded fills, path ops, `drawText` glyphs
* Fonts: system TTF via `dew.backend.font` (replaceable with `setUiFont`)
* Path-pin `../vello-d` until registry publishes `~>0.1.4`

=== wgpu / 3D

* [*x*] `MeshView` leaf + RGBA `ImageBlit` compositing
* [*x*] `Wgpu3dViewport` embed buffer + soft triangle placeholder
* [ ] Shared wgpu device with Vello (needs device export from vello-d)
* [ ] Real GPU mesh pipeline (vertex buffer + depth) into the embed

=== Touch / pointer

* [*x*] Pointer capture across Move / Up / Cancel
* [*x*] Multi-touch ids (up to 16 active contacts)
* [*x*] Drag vs tap (slop + `TouchCapability.Drag`)
* [*x*] Keyboard Tab focus cycle + Enter activate (`KeyEvent`)
* Higher-level gesture sugar lives in **dui** (`onGesture`)

=== Layout

* [*x*] `JustifyContent` honored when children do not flex-grow
* [*x*] `ScrollView` + scroll offsets + clip
* [*x*] Injectable text measure (`setTextMeasure`)
* [*x*] Optional `FlexWrap.Wrap` on horizontal stacks
* No full CSS grid; wrap is single-pass greedy rows only

=== Forms (engine primitives)

* [*x*] `TextField` / `CheckBox` node kinds + paint
* Bound helpers and validation live in **dui**

=== Memory / `@nogc`

* Arenas and `@nogc` UI thread are designed
* [*x*] Optional `UiBuilder.arena` + `beginFrame` interns text into the arena
* Main path still uses GC arrays for the node store / display list itself

=== Markup adapters

* Adapters are CTFE subsets / heuristics
* No Rust `i-slint-compiler` CLI integration

== App-kit (dui)

`dui` now ships forms, focus, navigation, and gesture helpers on top of dew primitives. See the dui roadmap for remaining app-kit polish.

== Ship / hygiene

* [*x*] Legacy **`rmgui`** DUB package **removed** from code.dlang.org — consumers use `dew`
* Local hive folder should be named `dew` (rename from `rmgui`); if Cursor still locks an old `rmgui` directory, close that workspace window and delete it
* Before a DUB tag: flip dui’s `path="../dew"` to `dew ~>0.1.4` after publishing dew; flip dew’s `path="../vello-d"` to `vello-d ~>0.1.4` after publishing vello-d
* Org Antora docs hub / public-readme chrome not fully wired (README already links Explore the docs)
* Binary Tailor one-file pack skipped for now (per-triplet zips instead)

== Out of scope for this file
