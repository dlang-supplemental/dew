== 2026-08-24 - Initial rmgui library

* Typed DSL (`VStack` / `HStack` / `Text` / `Button`), arenas, `Signal!T`, flex layout, display list.
* CTFE markup + adapters: Slint, QML, KDL, RSX, UXML, JSX, Godot, RON, JSON.
* Backends: software (CI), Vello 2D via registry `vello-d` (`-c gpu`), wgpu 3D viewport via `bindbc-wgpu`.
* `tgc` dependency for thread-local GC hosts; gallery example; CI + installers.
