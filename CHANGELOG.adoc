= changelog

== 2026-08-29 - Canvas, sticky backgrounds, multiline fields

* `NodeKind.Canvas` with optional rule grid; containers can `fillBackground` / `background(ColorRgba)`.
* `TextField.multiline` paints and measures `\n` lines; DSL `Canvas`, `multiline`, `background`, `showGrid`.
* Version **0.1.6**.

== 2026-08-28 - DPI / content scale

* New `dew.scale`: `ScaleFactor`, logical↔physical helpers, DPI/GLFW probes, `ContentScaleSource`.
* `App` layouts in logical units; display list scaled on present (`applyContentScale`).
* `examples/vello-window` syncs GLFW framebuffer + content scale.
* Version **0.1.5**.

== 2026-08-25 - Vello glyphs, paths, mesh embeds

* GPU backend honors clips, strokes, rounded fills, path ops, and system-font glyph runs (`vello-d` draw_text).
* `MeshView` + RGBA `ImageBlit` compositing; soft-triangle embed from `Wgpu3dViewport`.
* `examples/vello-window`: Linux X11/Wayland attach; send pointer Up (clicks fire on Up).
* Optional `UiBuilder.arena` for rebuild text interning.

== 2026-08-25 - Pointer capture, layout, forms primitives

* `PointerRouter`: capture, multi-touch Move/Up/Cancel, drag-vs-tap; buttons click on **Up**.
* `KeyEvent` + Tab focus cycle / Enter activate on `App`.
* Layout: `JustifyContent`, `ScrollView`, clip emitters, injectable text measure, optional wrap.
* DSL: `TextField`, `CheckBox`, `ScrollView`, `draggable`, scroll/clip helpers.
* Software backend clip stack; version **0.1.4**.

== 2026-08-24 - Windowed Vello demo + rmgui removed

* Added `examples/vello-window` (GLFW + `VelloRenderBackend`).
* Fixed VStack main-axis sizing for Text/Button (height, not width estimate).
* Removed legacy DUB package `rmgui` from code.dlang.org — use `dew` only.
* `dewVersion` reads `DEW_VERSION` so dependents' `VERSION` string-imports do not shadow.

== 2026-08-24 - Rename to dew + Dew it!

* Package/module rename `rmgui` → `dew`; tagline **Dew it!**
* Companion app-kit `dui` introduced (depends on `dew`).

== 2026-08-24 - Initial library (as rmgui)

* Typed DSL, CTFE markup, adapters, software/Vello/wgpu backends, `tgc`, gallery, CI, installers.
